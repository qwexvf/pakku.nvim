1. OVERVIEW                                               *pakku-overview*

pakku.nvim wraps |vim.pack| with four ergonomics:

  - lazy-load triggers (event/ft/cmd)
  - build hooks driven by |PackChanged|
  - dependency ordering via `dependencies = { ... }`
  - `opts → require(modname).setup(opts)` sugar

Plus optional supply-chain scanning via aegis-cli.

|vim.pack| keeps owning installs, updates, and the lockfile.

==============================================================================
2. REQUIREMENTS                                       *pakku-requirements*

  - Neovim 0.12+
  - aegis-cli on PATH (optional, for scanning)

==============================================================================
3. SETUP                                                     *pakku-setup*

>lua
    require("pakku").setup({
      scanner = {
        enabled = true,
        bin = "aegis",
        on = { "install", "update" },
        actions = true,
        sbom = true,
        fail_on = "block",
      },
    })

    require("pakku").add({
      { src = "https://github.com/folke/lazydev.nvim", ft = "lua", opts = {} },
    })
<

==============================================================================
4. SPEC FORMAT                                                *pakku-spec*

  src           string, required, git URL
  name          string, defaults to repo basename
  version       string | vim.version.range(…)
  modname       string, module name passed to require()
  opts          table, passed to require(modname).setup(opts)
  config        function, called instead of opts
  build         string | function
                  ":TSUpdate"  -> ex-cmd
                  "make"       -> shell via sh -c
                  fn(ctx)      -> ctx = { path, spec }
  event         string | string[], lazy-load on autocmd
  ft            string | string[], lazy-load on FileType
  cmd           string | string[], lazy-load on user command
  dependencies  spec[], installed and loaded before this plugin

==============================================================================
5. COMMANDS                                              *pakku-commands*

  :Pakku status              Active vs pending plugins.
  :Pakku update [name]       Forward to vim.pack.update.
  :Pakku clean <name>        Forward to vim.pack.del.
  :Pakku scan [name]         Run aegis-cli on one or all plugins.

==============================================================================
6. SCANNER                                                *pakku-scanner*

Scanner runs aegis-cli over each plugin path. aegis does NOT AST-scan Lua;
it covers GitHub Actions workflows and manifest-bearing transitive deps.
Pure-Lua plugins produce empty SBOMs. Review Lua source yourself.

==============================================================================
7. HEALTH                                                  *pakku-health*

`:checkhealth pakku` reports Neovim version, vim.pack presence, lockfile
location, aegis availability, and report directory.
